# 📊 Análise de Dados com Python

## 📌 Sobre o projeto

Este projeto tem como objetivo realizar uma análise exploratória de dados utilizando Python, passando pelas etapas de carregamento, limpeza, tratamento e organização das informações para gerar uma base preparada para análise.

O projeto demonstra um fluxo de trabalho de análise de dados, desde a importação dos dados brutos até a preparação de uma tabela final com variáveis tratadas.

---

## 🎯 Objetivos

- Realizar o carregamento da base de dados;
- Identificar e tratar dados inconsistentes;
- Realizar limpeza e organização das informações;
- Criar variáveis para auxiliar na análise;
- Preparar os dados para futuras análises e visualizações.

---

## 🔎 Etapas realizadas

### 1. Carregamento dos dados

Importação da base de dados utilizando bibliotecas Python para análise e manipulação das informações.

### 2. Tratamento dos dados

Foram realizadas etapas de:

- Verificação de valores ausentes;
- Padronização das informações;
- Correção de inconsistências;
- Organização das colunas.

### 3. Criação da tabela tratada

Após o processo de limpeza, foi criada uma versão organizada dos dados (`df_clean`), contendo informações preparadas para análise.

### 4. Dicionário de variáveis

Foi criada uma tabela de variáveis (`tabela_variaveis`) contendo a descrição e organização das informações presentes na base.

---

## 📈 Resultados

Ao final do processo, os dados ficaram estruturados e preparados para análises posteriores, permitindo a geração de insights e visualizações.
